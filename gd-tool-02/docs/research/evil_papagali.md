# Evil Papagali (Massacration): online resources

Researched 2026-11-19 (backlog R15) to improve the forged chart of the user's test song
(*Gates of Metal Fried Chicken of Death*, 2005, track 3, 4:51; metal, standard tuning).

| Resource | What it is | How it helps | Access |
|---|---|---|---|
| [RhythmVerse: Evil Papagali](https://rhythmverse.co/songfile/5f791240b326a6.07310279) | A human-made **Rock Band 3** custom (chart by prerigos / ONAONEMEU, converted by diogoblader; uploaded 2017-05-31, updated 2023-10-22; 196 downloads). Instrument list not readable without a browser | The best source: a full-band human chart. Song home can use a chart as-is per instrument once its notes.mid is out of the package | Download in a browser. Not found: a ready Clone Hero (`.chart` / `.sng`) version on Enchor (its search is a
browser app; check https://www.enchor.us/ by hand).

## What to do with them (in order of impact)

1. Download the RhythmVerse RB3 chart. If it's a CON file, we add a CON reader (L12) and
   drop it on the Guitar, Bass and Drums boxes. It must be checked for an offset against our
   audio (L02).
2. Paste the Cifra Club page into a `.txt` and drop it on the Guitar box (chords + lyrics).
3. Paste the lyrics into Lyrics > Type / paste (better than the forged guess).
4. With Songsterr Plus, the Guitar Pro file goes in the Guitar box.

Lyrics and tabs are copyrighted: the app keeps them in the user's own project folder, and
we don't copy them into the repo.
